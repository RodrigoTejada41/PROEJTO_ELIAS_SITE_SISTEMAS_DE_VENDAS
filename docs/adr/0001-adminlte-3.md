# ADR 0001 — AdminLTE 3

Estado: requisito confirmado em 03/11/2026.

Contexto: Esther Beauty 777 exige um template administrativo único. Decisão: AdminLTE 3, preferencialmente 3.2, com personalização externa e plugins selecionados. AdminLTE 4, Bootstrap 5 e templates concorrentes requerem aprovação explícita. Consequência: validar dependências, compatibilidade, segurança e acessibilidade antes de integrar. O stack completo permanece em proposta.
