# 12. PADRÃO DE QUALIDADE

Estabelecer uma política de qualidade baseada na stack existente.

Incluir:

- Formatação padronizada.
- Análise estática.
- Verificação de tipos, quando aplicável.
- Testes automatizados.
- Revisão de dependências.
- Verificação de segurança.
- Revisão de contratos.
- Testes de regressão.
- Critérios de aceite.

Toda correção de defeito reproduzível deverá, quando viável, possuir teste capaz de detectar sua recorrência.

Não impor percentuais arbitrários de cobertura sem analisar o projeto.
